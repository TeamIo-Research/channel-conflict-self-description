## §9 解析附則（英文臂專屬）

1. **答案 token 為 A／B／C**（中文批為甲／乙／丙）。E1 抽取＝第一行字元類過濾後恰等於單一字母。
2. **大小寫容錯**：第一行經 NFKC 正規化並轉大寫後比對——`a`／`A` 均判定為 A。（英文交付方於「假設與缺口」第 8 項指出委託書未定此項；此為 Code 補訂的解析附則，非刺激材料變更。）
